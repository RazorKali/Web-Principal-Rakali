# Rakali Soluciones Informáticas

Sitio web corporativo de Rakali Soluciones Informáticas, empresa chilena enfocada en desarrollo de software, infraestructura tecnológica, redes, soporte informático, servidores, monitoreo y consultoría TI.

## Tecnologías

- React
- Vite
- JavaScript
- HTML5
- CSS3
- Lucide React

## Instalación

```bash
npm install
```

## Ejecución

```bash
npm run dev
```

## Compilación

```bash
npm run build
```

## Estructura General

```text
src/
  assets/
  components/
  config/
  data/
  pages/
  styles/
  App.jsx
  main.jsx
```

## Configuración

Los datos principales de la empresa se centralizan en `src/config/company.js`.

El archivo `.env.example` documenta variables opcionales para futuras integraciones, sin incluir credenciales.
